Set up Muse Life Graph

Muse Life Graph runs on this computer and reads your photos where they are. First choose who looks at them: a model on this computer (free and private, slower), or Meta's models in the cloud (faster and sharper, about $0.006 a photo, paid to Meta directly). You can change this later.

1 · Where should Muse look at your photos?

Checking this computer…
No local model server is running. Install Ollama (or LM Studio), then get a model: ollama pull Muse Glimmer for everything here, or any vision model for pictures only. Then reopen this page.
Best: Meta's Muse Glimmer (open weights). A smaller vision model works for "pictures here". Speech is heard on this computer by Whisper when it is installed.

2 · Your Meta Model API key (not needed when everything runs here)

  1. Open dev.meta.ai and sign in.
  2. Create an API key and copy it.

3 · Your graph database (free)

  1. Open console.neo4j.io and create a free AuraDB Free instance.
  2. Download its credentials file when it offers it: it has the address and the password.
For everything on this computer, install Neo4j locally instead and use bolt://localhost:7687: then not even the descriptions leave your machine.

4 · Muse Spark Open on Baseten (optional, cloud modes)

With a Baseten key, search, memory titles and the picture checker run on Meta's open-weights model. Without one, everything uses your Meta key.

Your keys are saved only on this computer, in your app folder, and sent only to the services they belong to. Your photos are read where they are; with "everything on this computer" or "pictures here" they are never sent anywhere.
